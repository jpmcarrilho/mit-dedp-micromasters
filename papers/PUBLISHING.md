# Publishing a paper

Working-paper venues in economics are SSRN and RePEc; arXiv is secondary and needs an endorsement for a new submitter. Follow the steps in order; each later step links to the earlier ones.

## 1. GitHub release and Zenodo DOI
1. Enable the repository once at https://zenodo.org/account/settings/github/ (sign in with GitHub).
2. Create a GitHub release with tag `pNN-vX.Y` and attach `output/paper.pdf`.
3. Zenodo mints a DOI for that release; add it to the paper's README and title page, then re-release as `vX.Y+1` if the PDF changed.

## 2. SSRN (free, no endorsement)
1. Account at https://www.ssrn.com; affiliation can be "Independent" or the author's organisation.
2. Submit a paper: PDF, English abstract, keywords, JEL codes; pick the Development Economics and Labor eJournals when offered.
3. Put the Zenodo DOI and the GitHub URL in the abstract page.

## 3. MPRA, Munich Personal RePEc Archive (free, indexed in RePEc/IDEAS)
1. Register at https://mpra.ub.uni-muenchen.de/.
2. Upload the same PDF with abstract, keywords and JEL codes; the paper appears on IDEAS/RePEc within days.
3. Create a RePEc author profile at https://authors.repec.org/ so the papers aggregate under one name.

## 4. arXiv (econ.GN), only when an endorser is available
- Policy since 2026-01-21: a new submitter needs either an institutional email plus a prior arXiv paper in the domain, or a personal endorsement from an established arXiv author in the econ domain. An unaffiliated author must use the personal route.
- Finding an endorser: on any recent econ.GN abstract page follow "Which authors of this paper are endorsers?"; ask one person at a time with the PDF and the code link. Course TAs, J-PAL affiliates and Brazilian academics who post to econ.GN are natural candidates.
- Do not block the series on arXiv.

## 5. Brazilian peer feedback
- ANPEC, Encontro Nacional de Economia (December): submissions usually open in the first half of the year; check https://www.anpec.org.br/.
- SBE, Encontro Brasileiro de Econometria: held alongside ANPEC; check https://www.sbe.org.br/.
- Both need a Portuguese abstract; the paper itself can be in English.

## 6. JEL codes used in this series
I26 Returns to Education; J31 Wage Level and Structure; O15 Human Resources; O54 Latin America; C83 Survey Methods; D72 Political Processes; H75 State and Local Government: Health, Education.
